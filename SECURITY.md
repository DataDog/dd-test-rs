# Security Policy

## Reporting a vulnerability

Do not open public GitHub issues for security vulnerabilities.

Report them privately through one of these channels:

1. [GitHub Security Advisories](https://github.com/DataDog/dd-test-rs/security/advisories/new) for this repository.
2. Email to `security@datadoghq.com`.

Include:

- The affected version or commit.
- Steps to reproduce, or a proof of concept.
- The impact you expect.

## What to expect

- We acknowledge your report as quickly as possible.
- We investigate it, confirm the impact, and work on a fix.
- When a fix is available, we agree on the disclosure timing with you.

## Supported versions

Security fixes are released for the latest version only.
